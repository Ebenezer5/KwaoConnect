# 📡 Zynk

Zynk is a telecom simulation web application that allows users to buy Airtime, Data, and SMS bundles using a virtual wallet system.

This project was built as a frontend telecom system simulation to demonstrate authentication, local storage management, session handling, and dynamic balance updates using JavaScript.

---

## 🚀 Features

### 🔐 Authentication System
- User Signup with validation
- Secure password hashing (SHA-256)
- Login system
- Auto login after signup
- Dashboard session protection

### 💰 Wallet System
- Airtime Balance
- MoMo Balance
- Data Balance
- SMS Balance

### 📦 Buy Packages
- Buy Airtime bundles
- Buy Data bundles
- Buy SMS bundles
- Choose payment method (Airtime or MoMo)
- Real-time balance deduction
- Prevent duplicate transactions

### 🎨 User Experience
- Dark / Light Theme (Saved in localStorage)
- Auto image slider
- Responsive layout
- Clean dashboard UI

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage API
- Web Crypto API (SHA-256 hashing)
- GitHub Pages (Deployment)
